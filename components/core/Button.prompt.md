Primary call-to-action button, used for the main conversion action on a page ("Book a Strategy Call").

```jsx
<Button variant="primary" arrow>Book a Strategy Call</Button>
<Button variant="secondary">Learn more</Button>
<Button variant="ghost" arrow>Explore How We Help</Button>
```

Variants: `primary` (solid navy, main CTA), `accent` (solid teal, secondary emphasis), `secondary` (outlined), `ghost` (text link with optional arrow, used inline in section headers). Sizes: `sm`, `md`, `lg`. Set `arrow` to append the site's signature "→".
