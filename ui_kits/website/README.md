# SumoLab Website UI Kit

Recreation of the live homepage at https://sumolab.co, built from the page's rendered content (fetched as text — no codebase or Figma access was available for this brand). One surface: the marketing website. No app/product beyond it exists for SumoLab.

Files: `Header.jsx`, `Hero.jsx`, `ProblemSolution.jsx` (Gap + Solution sections), `BenefitsSection.jsx`, `TestimonialsSection.jsx`, `FounderFeatures.jsx` (About Jerry + Features list), `FAQCTA.jsx` (FAQ accordion + final CTA), `Footer.jsx`. Composed in `index.html`.

All photography (hero shot, team photo, founder headshot, client headshots) is a labeled gray placeholder — the real images live on sumolab.co but weren't fetchable as binaries from this environment. Swap in real photo assets when available.
